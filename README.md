# ONE PATRON

ONE PATRON is a conceptual artwork by Alexander List: one patron, at least USD 1,000,000 in cryptocurrency, and nothing sold in return.

This repository preserves the public-facing core website and Protocol, ENOCH, Relational Depth, published stories, visual identity, selected production assets, and the signed Origin Record and provenance materials of the project.

## Repository structure

- `brand/` — current public visual identity masters and standards.
- `stories/` — published story texts and approved covers.
- `site/` — clean public source subset after the TO BE KNOWN withdrawal; not a full reproducible export of production. Existing historical source differences are retained.
- `social/` — current public social-media assets.
- `media/` — selected public audiovisual works.
- `source-code/` — scripts used to produce project assets.
- `provenance/` — signed Origin Record, public record links and rights notice.

The unreleased hidden-score architecture, owner runbooks, private drafts and superseded variants are intentionally not included in this public subset.

See `provenance/RIGHTS_NOTICE.md` for rights information.


## Availability and repository transition

This repository starts with new history. It does not import or replace the original repository history, which is retained privately. TO BE KNOWN v0.2.0 is withdrawn; [the public notice](https://one-patron.com/depth/to-be-known/) is not the authenticated machine work or a successor.

Historical signed records and checksum inventories are retained unchanged. References in those records to the original repository and its commits are historical identifiers, not promises of current public access. See [the Verification Center](https://one-patron.com/verification/) for unchanged signed identity and Origin records. This transition does not alter the public Protocol.
